## 修复：前端对话不显示 + token 指标不显示（后端接口缺失）

**根因**：最近一次前端大改（commit d69d30e「修改前端」）把对话请求从旧的 `GET /app/chat/gen/code`（EventSource）换成了 `POST /app/chat` 与 `POST /app/chat/workflow`（fetch 读 SSE），但后端只实现了旧的 GET 接口，没有这两个 POST 接口 → 前端所有对话请求 404，对话内容不显示，token 指标也拿不到最新数据。

**修复内容**：
- 新增 `epiph-code-monolith/src/main/java/com/ai/epiphcode/model/dto/app/ChatGenerationRequest.java`：JSON 请求体 DTO（appId/message/mode/agent/clientRequestId/baseVersionId）。
- `AppController.java`：新增 `POST /app/chat`（classic）与 `POST /app/chat/workflow`（workflow），两者复用抽取出的私有方法 `streamChat(...)`，与旧 GET 接口共用幂等防重、限流、SSE 封装逻辑；旧 GET 接口保留兼容。
- `AppChatPage.vue`：token 展示pill从只显示 total 改为完整显示 输入/输出/合计（`inputTokens`/`outputTokens`/`totalTokens`）。

**验证**：前端 `npm run type-check` 通过；后端 `./mvnw -pl epiph-code-monolith -am compile -DskipTests` 通过（exit 0）。

**注意**：微服务模块 `epiph-code-microservice` 也有一份旧的 `GET /chat/gen/code`，README 说明当前实际使用单体后端（8123），微服务本次未改。
