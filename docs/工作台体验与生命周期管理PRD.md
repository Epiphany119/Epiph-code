# Epiph-code Studio 工作台体验与生命周期管理 PRD

## 1. 背景与目标

随着 Epiph-code Studio 支持原生 HTML、原生多文件与 Vue 3 工程三种代码生成模式，并引入了 DAG 任务计划（`updatePlan`）、Nag 提醒机制与不可变网页版本管理，用户在实际创作与测试过程中暴露出四类高频体验与运维痛点：

1. **生成过程与多文件代码阅读不便**：单轮 Vue 工程对话包含十余个文件及多轮思考/工具调用，原界面分栏固定且偏窄、原始 JSON 与内部符号（`#`、`##`、`[x]`、`[>]`、`<reminder>`）直接暴露，用户难以专注查阅代码与执行轨迹。
2. **作品管理与社区精选缺少入口**：首页作品卡片无法直接区分 HTML、多文件与 Vue 工程类型；创作者无法主动将自己的优质作品加入「精选应用展示」；删除不用的作品缺少便捷入口。
3. **长期运行磁盘占用风险**：用户删除应用后仅做逻辑删除，数据库记录与本地 `tmp/` 下的生成目录、不可变快照、部署目录和截图持续累积，长期运行存在磁盘空间耗尽风险。
4. **测试与找回账号密码受阻**：当前用户体系未接入邮箱/短信服务，测试或忘记密码时无法找回历史作品。

本 PRD 旨在明确上述能力的交互规范、后端策略与验收标准，打造统一、克制、清晰的 **Google Material Design 3** 工作台体验。

## 2. 功能范围与详细需求

### 2.1 对话工作台灵活分栏与全屏代码/过程检视

#### 1）可拖拽分栏与预览全屏
- 对话区与页面预览区之间提供可拖拽垂直调节线，支持 **24% ～ 76%** 宽度平滑调节，拖拽期间屏蔽 `iframe` 指针拦截，松手后自动将比例持久化至 `localStorage`，双击调节线恢复默认比例（42%）。
- 预览区顶部提供「全屏预览 / 退出全屏」按钮，支持一键隐藏左侧对话栏专注查看网页效果。

#### 2）代码文档与工具调用分离检视
- **代码文档全屏查看器（`MarkdownRenderer`）**：
  - 每个生成的代码块顶部展示识别出的文件名（如 `package.json`、`src/App.vue`）与语言标签，右上角提供「复制」与「全屏」按钮。
  - 点击任意代码块的「全屏」按钮进入全屏代码视图；当单轮回复包含 **2 个及以上代码块**（多文件 / Vue 工程）时，全屏左侧自动展开「文件列表」侧边栏（超过 5 个文件自动显示文件名筛选框），用户无需反复进出全屏即可连续浏览全部文件。
- **思考与工具调用结构化检视（`ProcessTimeline`）**：
  - 将每轮的思考过程与工具调用统一归集在「思考与工具调用 · N 步」卡片中，与下方「最终回复」代码文档区清晰分离，并支持独立打开全屏侧边栏检视。
  - 文件类工具（`writeFile`、`modifyFile`、`readFile`、`readDir`、`deleteFile`）必须在标题中显式标明目标文件名（如 `写入文件 · src/main.js`），展开后直接以语法高亮代码或「替换前 / 替换后」对照呈现，不再直接输出转义后的原始 JSON。
  - `updatePlan` 渲染为带进度条、圆形步骤号、状态胶囊（`已完成` / `进行中` / `待处理`）与前置依赖标签的结构化任务清单，移除冗余的原始 ASCII 返回文本与 `#`、`[]` 符号。
  - **Nag 机制可视化**：保留后端注入的 `<reminder>...</reminder>` 计划更新提醒，将其与工具执行结果分离，渲染为独立的「Nag 机制 · 计划更新提醒」卡片，展示提醒说明、当前完成进度及去符号化后的任务快照。

### 2.2 作品类型标记、精选展示入口与账户名称同步

- **代码类型标记**：首页每张作品卡片底部按 `codeGenType` 展示独立配色的类型胶囊（`HTML`、`多文件`、`Vue 工程`），便于快速区分工程形态。
- **一键添加 / 取消精选**：
  - 单体后端提供 `POST /app/featured`（入参 `id`、`featured`），校验应用所有者或管理员权限后在 `priority = 99`（精选）与 `0`（普通）之间切换，并主动清理 `good_app_page` Redis 缓存。
  - 前端「我的作品」卡片右下角提供星标切换按钮（空心星 / 金色实心星），点击后实时同步刷新「我的作品」与「精选应用展示」列表。
- **账户名回退同步**：当用户昵称 `userName` 为空或默认占位值「无名」时，头部导航、作品卡片、应用详情与对话头像统一回退显示真实账号 `userAccount` 及其首字母。

### 2.3 应用删除 30 天保留与磁盘产物自动清理

- **前端删除入口**：首页「我的作品」卡片右下角与对话页「应用详情」弹窗均提供删除按钮，二次确认文案明确告知「删除后数据将在数据库保留 30 天，到期后彻底清理数据库记录及本地产物」。
- **后端延迟物理清理（`AppCleanupService`）**：
  - 用户删除时先执行逻辑删除（`isDelete = 1`，更新 `updateTime`），前端立即不可见，数据库保留 30 天（可通过 `epiphcode.cleanup.retention-days` 配置）。
  - 后端开启 `@EnableScheduling`，在**服务启动完成时**与**每日凌晨 03:00** 自动扫描 `isDelete = 1` 且 `updateTime <= NOW() - retentionDays` 的过期应用。
  - 清理单条过期应用时，先递归删除 `tmp/` 下的全部本地产物：
    - 生成工作区：`tmp/code_output/*_{appId}`
    - 不可变版本快照：`tmp/code_versions/{appId}`
    - 本地部署目录：`tmp/code_deploy/{deployKey}`
    - 应用封面截图：`tmp/screenshots/{相对路径}`
  - 随后在事务中物理删除 `chat_history`、`chat_event_log`、`app_version`、`app_deployment_history` 与 `app` 表对应记录。

### 2.4 管理员重置用户密码

- 后端在 `UserController` 提供 `POST /user/reset/password`（`@AuthCheck(mustRole = "admin")`），接收 `id` 与可选 `newPassword`（留空默认重置为 `12345678`，自定义密码长度不少于 8 位），经统一加盐 MD5 加密后更新数据库。
- 前端管理员「用户管理」页面操作列新增「重置密码」按钮与弹窗；登录页新增「忘记密码？」入口提示用户联系管理员重置。

### 2.5 Google Material Design 3 视觉规范与代码生成准则

- **控制台视觉规范**：全站采用纯白 `#FFFFFF` 画布、`#F0F4F9` / `#F8F9FA` 柔和容器、`1px solid #DADCE0` 细描边、`#0B57D0` Google Blue 点缀、规范苹果系统字体栈（`-apple-system, BlinkMacSystemFont, 'SF Pro Text', 'PingFang SC'`），以及浅色柔和代码块主题。
- **模型生成提示词规范**：在 HTML、多文件与 Vue 3 工程的系统提示词中增补 Gemini / Material 3 默认视觉与交互准则（纯白通透画布、克制单一主色、圆弧几何与版心留白、规范系统字体与 CSS 变量、真实客户端交互反馈），修改场景继续遵循最小改动原则。

## 3. 验收标准

1. **分栏与全屏**：对话与预览可流畅拖拽调宽且刷新后保留比例；多文件/Vue 工程代码全屏自动显示左侧文件列表并可快速切换；工具调用全屏独立展示全部执行步骤且 `writeFile` 明确标明文件名。
2. **结构化与 Nag 渲染**：`updatePlan`、`writeFile`、`thinking` 与 `<reminder>` Nag 提醒均已结构化渲染，界面中不出现原始 `<reminder>`、`#1`、`##1`、`[x]`、`[>]`、`[ ]` 符号。
3. **作品标记与精选**：首页作品卡清晰展示 `HTML` / `多文件` / `Vue 工程` 标签；点击星标可实时将作品加入或移出「精选应用展示」。
4. **30 天清理机制**：删除应用后前端立即移除，数据库保持 `isDelete = 1`；将测试记录 `updateTime` 调早至 30 天前并重启后端后，数据库 5 张关联表记录与 `tmp/` 下对应产物目录被彻底清除。
5. **管理员重置密码**：管理员账号在「用户管理」中可为任意用户重置密码，被重置用户可使用新密码正常登录并查看原有作品与历史对话。
